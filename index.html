X API USER LOOKUP

Does this user exist?

Check an X account directly through the X API. Your token is used only for this request and is never stored.

Requires an X developer bearer token with access to the v2 Users endpoint.

Requests go to api.x.com/2/users/by/username. If your browser blocks the request due to CORS, make the same call from a small backend proxy so the bearer token stays private.
